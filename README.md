# Практична 5
1. Реалізувати скінчений автомат для розпізнавання наявності в рядку слова "ТEST":
 - на вхід подається рядок з довільною кількістю символів
 - автомат бере з рядка по одному символу і в залежності від свого стану і символу, який автомат прийняв, він змінює свій стан.
 - якщо символи в рядку закінчуються, автомат закінчує свою роботу і повертає свій кінцевий стан. Стан F показує, що послідовність символів "TEST" була наявна у вхідному рядку. Наприклад, результати роботи для рядків:
 "abcTESTabc" ->F
 "abcTES" -> 3
2. Написати Unit тести для даної реалізації зі всіма функціональними кейсами. Використовувати параметризацію.
3*(завдання із зірочкою). Існують такі рядки зі словом "TEST" при яких автомат не буде переходити в стан F. Необхідно знайти їх, пофіксити реалізацію і написати на ці кейси тести.
